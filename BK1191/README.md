## About This Demo

Demo repository for showcasing Detection-as-Code workflows in Falcon NG-SIEM.

## Structure

- `detections/` - Detection rules in various pipeline stages
- `session-resources/` - Templates, docs, and demo materials
- `scripts/` - Automation tools
- `tests/` - Validation and testing

## Pipeline Stages

1. **stage-review** - Pending approval
2. **stage-validate** - Post-approval testing
3. **prod-active** - Live production rules
4. **prod-archive** - Retired rules
